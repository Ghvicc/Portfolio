# Portfolio

This is a simple personal portfolio website consisting of a single-page static site.

## Overview

- Purpose: Showcase projects, work samples, and contact information.
- Files: `index.html` is the site entry point. Images and assets are stored in `img/`.
- Technologies: Plain HTML and assets (no build step required).

## How to view

- Open the site locally by double-clicking `index.html` in your file explorer, or serve it from a local web server:

```bash
# Python 3 built-in HTTP server
python -m http.server 8000
# Then open http://localhost:8000 in your browser
```

## Deployment

Recommended simple options:

- GitHub Pages:
  1. Push this repository to GitHub.
  2. In repository settings, enable GitHub Pages and select the `main` branch (or `gh-pages` branch) as the source.
  3. Your site will be available at `https://<your-username>.github.io/<repo-name>/`.

- Netlify / Vercel: Drag-and-drop the site folder or connect your GitHub repo.

## Project structure

- `index.html` — main page
- `img/` — images and media

## Customization

- Edit `index.html` to update content, add projects, or change text and links.
- Replace or add images inside the `img/` folder and update references in `index.html`.
